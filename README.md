# meridian-plugin-usage

Meridian V1's open-source Usage plugin: immutable metering events, exact unit
normalization, bounded queries, deterministic aggregation, retention inputs,
and OpenTelemetry/Evidence correlation over logical Meridian Resources.

The distribution is a library and plugin, not a service or a Usage Catalog. It
owns no database, provisions no engine, accepts no engine credentials, and
uses only released Meridian mapping-first Expressions.

Status: implementation in progress for the initial 1.0.0 release.
